Basics - Code Organization for Competitive Programming

Overview
- Codeforces problems are organized by letter category under cp/src/codeforces/
- A problems live in A/, C problems in C/, etc.
- Build artifacts live in cp/build/; executables in cp/bin/
- External projects live under projects/
- Utilities and scripts live under utils/
- Documentation lives under docs/

Notes
- This layout is non-destructive and ready to apply. Adapt paths as needed.
- For new problems, follow the A/C naming conventions (e.g., 1374A.cpp → cp/src/codeforces/A/1374A.cpp)
