# Codeforces Beginner 100 — Practice Solutions

Standalone GNU C++17 solutions for the 100 problems listed in the user-provided PDF, kept in the same order. The source is formatted for readability; use these files as practice references and make sure you understand and can explain a solution before submitting your own work. These files are not submitted to Codeforces.

Compile an individual solution with:

```sh
g++ -std=c++17 -O2 -Wall -Wextra -pedantic <solution.cpp> -o solution
```
